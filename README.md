Sistema Punto de Venta Cafetería Sunflower Coffee Bar

Autores: Cristobal Estudillo Gerardo, Leal Vicario Adilene

Asignatura: Ingeniería de Software.
Docente: Raúl Cruz Romero

Descripción:
El siguiente repositorio muestra el código de un sistema de punto de venta 
para la cafetería Sunflower Coffee Bar. Este sistema permite administrar y llevar un
control de las ventas del negocio y de los productos del invnetarios de forma eficiente.
El sistema está conectado a una base de datos de MySQL, por lo que aunque se utilicen los códigos
para generar la interfaz gráfica, también será necesario utilizar conectores para acceder a la
base de datos desde el programa e importar las librerías para MySQL de Java.

Tecnologías utilizadas:
El programa fue hecho principalmente utilizando lenguaje de progrmación Java con el programa NetBeans.
La base de datos fue hecha en MySQL Workbench.
También fue necesario el uso de conectores de Java para acceder a la base de datos.

Para ejecutar el programa, bastará con el uso de NetBeans copinado los módulos en archivos
Empty Java File, instalar los conectores e importar la librería de MySQL.
